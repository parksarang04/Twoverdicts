# 두 개의 판결 (Twoverdicts)

> 인간이 정한 법으로 한 사람의 인생을 판단할 자격이 있는가?

흑백 화면 속 사건 현장을 직접 걸어 다니며 단서를 모으고, 단서를 연결해 진실을 추리한 뒤 마지막에 직접 판결을 내리는 2D 추리 게임입니다.

![조사 화면](docs/screenshot_investigation.png)

## 게임 정보

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 흑백 추리 · 판결 |
| 엔진 | Unity 6 (C#) |
| 개발 | 박사랑 (개인 프로젝트, 기획 · 개발) |
| 기간 | 2026.10 ~ |

## 핵심 시스템

### 1. 행동 횟수가 정해진 조사
- 화면 오른쪽 위에 **남은 행동**이 표시됩니다.
- 조사와 대화 모두 행동을 소모하기 때문에, 무엇을 먼저 확인할지 고민해야 합니다.
- 반짝이는 오브젝트는 단서, `!` 표시는 대화할 수 있는 사람입니다.

### 2. 추리 보드
- 모은 단서 두 개를 골라 연결하면 새로운 사실이 드러납니다.
- 조합 목록에는 결론 문장만 보이고 재료는 `[???]`로 가려져 있어, 어떤 단서를 찾아야 하는지 방향을 잡을 수 있습니다.

| 단서 연결 | 조합 목록 |
| --- | --- |
| ![추리 보드 - 단서 연결](docs/screenshot_board_connect.png) | ![추리 보드 - 조합 목록](docs/screenshot_board_list.png) |

### 3. 흑백과 빨간색
- 화면 전체는 흑백이고, 중요한 오브젝트에만 빨간색을 씁니다.
- 조사가 진행될수록 인물이 점점 선명해집니다.
- 모든 단서를 모은 뒤, 플레이어가 직접 판결을 내립니다.
